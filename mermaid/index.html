Mermaid syntax help

Most Mermaid diagrams start with a diagram type such as flowchart, sequenceDiagram, classDiagram, stateDiagram-v2, erDiagram, or gantt. Comments use %%.

General shape

%% comment
flowchart TD
A[Start] --> B[Finish]

Common parser gotchas

flowchart TD
A --> B[End]

Direction keywords

flowchart TD
flowchart LR

Styling basics

flowchart LR
A --> B
style A fill:#e8f1ff,stroke:#4d89ff
style B fill:#eaffea,stroke:#2c9b45

Basic flowchart

flowchart TD
A[Start] --> B{Decision}
B -->|Yes| C[Do thing]
B -->|No| D[Stop]

Subgraph

flowchart LR
subgraph Backend
  A[API] --> B[DB]
end
C[Browser] --> A

Node styles

flowchart TD
A[Rectangle]
B(Rounded)
C{Diamond}
D((Circle))
A --> B --> C --> D

Basic sequence

sequenceDiagram
participant U as User
participant A as App
U->>A: Submit request
A-->>U: Response

Alt / else

sequenceDiagram
Alice->>Bob: Check status
alt success
  Bob-->>Alice: Approved
else failure
  Bob-->>Alice: Rejected
end

Basic class diagram

classDiagram
class Animal {
  +String name
  +eat()
}
class Dog {
  +bark()
}
Animal <|-- Dog

State diagram

stateDiagram-v2
[*] --> Draft
Draft --> Review
Review --> Approved
Approved --> [*]

erDiagram
